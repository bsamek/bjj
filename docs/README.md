# BJJ Study

A React application for Brazilian Jiu-Jitsu study and training. Track techniques, positions, and principles to improve your game.

## Features

- **Position Management** - Study 11 fundamental BJJ positions (Closed Guard, Open Guard, Half Guard, Side Control, Mount, Back Control, Turtle, North-South, Knee-on-Belly, Standing/Takedowns)
- **Technique Tracking** - Document techniques with descriptions and personal notes
- **Top/Bottom Perspectives** - Organize techniques from both dominant and defensive viewpoints
- **Core Principles** - Track universal BJJ concepts and position-specific principles
- **"Do First" Priorities** - Mark your go-to techniques for each position
- **Transitions** - Document how to move between positions
- **Cloud Sync** - Data syncs via Firebase Firestore with Google authentication
- **Works Offline** - Local storage fallback when offline

## Technology Stack

- React 19 with TypeScript
- Vite for build tooling
- Tailwind CSS for styling
- Firebase (Authentication + Firestore)
- Vitest for testing
